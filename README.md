# ☕ Coffe Page com Slider de Imagens 

O destaque é o **Modo Slide de Imagens**, que permite navegar pelas fotos de forma suave e responsiva.

## ✨ Destaque: Modo Slide (Carrossel)

A galeria de imagens principal utiliza JavaScript puro para criar um carrossel que funciona em loop, com botões de navegação **Próximo** e **Anterior**.

* O slider garante uma experiência visual fluida e moderna.
* Perfeito para destacar produtos ou momentos-chave do seu negócio.

## 🛠️ Tecnologias Utilizadas

| Arquivo | Descrição |
| :--- | :--- |
| **`index.html`** | Estrutura semântica do site (Home, Menu, Avaliações, Contato). |
| **`style.css`** | Responsável por todo o design, cores, e layout responsivo. |
| **`script.js`** | Contém a lógica de navegação do menu e, principalmente, o **código do slider de imagens**. |
